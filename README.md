# Smart Recipe & Inventory Manager

Une application web qui aide à lutter contre le gaspillage alimentaire. Il suffit de prendre une photo de son réfrigérateur ou de son placard : l'application identifie automatiquement les ingrédients présents et propose des recettes adaptées.

## Table of Contents

* [Preview](#preview)
* [Features](#features)
* [Installation](#installation)


## Features

* Détection automatique des ingrédients à partir d'une simple photo
* Estimation de la quantité et de l'état de maturité des aliments
* Suggestion de recettes générées ou trouvées dans une base existante
* Historique de l'inventaire dans le temps
* Interface web responsive
